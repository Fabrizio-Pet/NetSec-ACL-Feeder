# 🛡️ NetSec ACL Feeder
**Automated Threat Intelligence & Cisco ACL Generator**

This project bridges the gap between traditional Network Engineering and modern Security Automation (NetSecOps). It is a Python-based tool designed to automatically ingest edge-router logs, analyze suspicious IP behavior using Threat Intelligence APIs, and dynamically generate Cisco IOS Access Control Lists (ACLs) to block verified threats.

---

## 📖 The Story Behind This Project
As a student who aspires to become a Network Engineer, I frequently design and simulate network architectures using tools like **Cisco Packet Tracer**. However, real-world edge routers and firewalls face constant brute-force attacks. I built this tool to automate the defensive response: instead of manually reading logs and typing `deny ip host...` on the CLI, this script does the heavy lifting, acting as a lightweight, automated SOC analyst.

---

## 🚀 Features
- **Log Ingestion & Parsing:** Reads raw syslog files from network devices and extracts malicious connection attempts (e.g., denied SSH/RDP traffic).
- **Threshold Filtering:** Only analyzes IPs that exceed a specific threshold of failed attempts (preventing API spam and saving bandwidth).
- **Threat Intelligence Integration:** Interacts with external REST APIs (simulated via `httpbun.com`) to evaluate the risk score of the attacker.
- **Dynamic ACL Generation:** Automatically outputs a `.conf` file containing syntactically correct Cisco IOS commands ready to be pasted or pushed via automation (e.g., Ansible/Netmiko).
- **JSON Reporting:** Generates a structured Threat Reputation Report for further SIEM integration.

## ⚙️ Installation & Usage

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/YourUsername/NetSec-ACL-Feeder.git](https://github.com/YourUsername/NetSec-ACL-Feeder.git)
   cd NetSec-ACL-Feeder
   ```

2. **Install the required dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the automation script:**
   ```bash
   python netsec_acl_feeder.py
   ```
   *Note: The script will automatically read the sample log from the `samples/` directory and generate the output files in the `output/` directory.*
